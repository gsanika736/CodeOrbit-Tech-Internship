CodeOrbit Tech Internship – Python Projects
Project Overview

This repository contains three Python projects completed as part of my CodeOrbit Tech Internship.

Projects
1. Simple Calculator: 
Performs addition, subtraction, multiplication, and division.
Takes user input.
Handles invalid inputs and division by zero using try/except.

2. To-Do List CLI App: 
Add new tasks.
View all tasks.
Remove tasks.
Uses Python lists and functions.

3. Number Guessing Game: 
Generates a random number.
Provides too high and too low hints.
Tracks the number of attempts.
Allows users to play multiple rounds.

Technologies Used:
Python 3,
Lists,
Functions,
Loops,
Conditional statements,
Exception handling,

Setup Instructions:
Install Python 3.
Download or clone this repository.
Open the project folder in VS Code or another Python editor.
Run the Python files using:

python calculator.py
python todo.py
python guessing_game.py
